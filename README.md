# Digital Signal Processing with MATLAB

A collection of MATLAB laboratory exercises completed as part of my
Autonomous Vehicle Engineering studies at Technische Hochschule Ingolstadt.

## Topics Covered

- LTI systems
- Transfer functions
- Pole-zero analysis
- Frequency response
- Digital filtering
- Windowing
- Fourier analysis
- Sampling and reconstruction
- Aliasing and anti-aliasing
- Downsampling
- Time-frequency analysis

## Tools

- MATLAB
- MATLAB Signal Processing Toolbox

## Labs

### Lab 02
Analysis of discrete-time systems, transfer functions, pole-zero
representations, frequency responses and digital filtering.

### Lab 03
Digital signal filtering and frequency-domain analysis.

### Lab 04
Sampling, aliasing, downsampling, anti-aliasing filtering and
time-frequency analysis.
